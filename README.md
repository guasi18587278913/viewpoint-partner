# 观点搭档（viewpoint-partner）

从得到文章和阅读书库中寻找适合当前话题的观点、可引用原话及支撑事例。

本仓库包含完整技能入口及所需的本地脚本和参考文件。使用流程从 [SKILL.md](SKILL.md) 开始。

## 获取与使用

```bash
git clone https://github.com/guasi18587278913/viewpoint-partner.git
```

仓库根目录就是技能目录。将整个目录放入所用客户端的技能目录；保留目录结构，不只复制 SKILL.md。已有同名技能时，先检查本地修改再合并。

调用示例：`用 viewpoint-partner，根据我提供的材料完成观点搭档任务。`

## 运行条件

检索依赖使用者自己的阅读库、索引及 Python 环境；这些私有资料不随仓库上传。请先阅读 [检索配置](references/retrieval.md)，使用 `VIEWPOINT_CORPUS_ROOT` 指向包含 `src/prw/corpus.py` 的阅读库，使用 `VIEWPOINT_BOOK_ROOT` 指向书籍库。本仓库并非得到全文库，也不是可独立使用的语义搜索服务。

脚本（如有）使用 Python 3；具体命令及可选依赖以技能正文、脚本帮助和参考文档为准。仓库不包含私有知识库、API 密钥、登录态或本次创作任务的数据。
