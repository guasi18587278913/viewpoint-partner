## 发现与修正

1. **无页码的书被跳过**：实库《干得漂亮》没有页码标记。增加完整文本记录与字符续读，不虚构页码。
2. **同书多文件编号碰撞**：独立临时夹具复现。完整 ID 加文件标识，简写仅在唯一匹配时可用；歧义明确报错。原夹具已复验。
3. **PDF 硬换行把词拆开而漏检**：实库“独立思\n考”复现。仅检索视图拼接中文单个硬换行；原文、位置和逐字核对不变，双换行不合并。原页已复验。
4. **错误卡片类型缺少结构化错误**：数字 ID 原本触发未捕获错误。三项 source 字段改为非空字符串，15 种字段/值组合纳入一项回归，CLI 退出 2。
5. **AI 误命中 Airbnb/mail**：行为测试发现。纯英文查询使用词边界，保留 AI写作；OpenAI/AIGC 需分别检索。对 C5 的七条原查询做了 回放（历史记录，未随包提供），去掉部分字母误命中，原来全文采用的四篇仍可召回。回放发生在词边界修复后、摘要窗口修复前；最终窗口修复仅改变摘录评分与边缘，已对其复现夹具单独回归，未宣称重新生成全部六份成品。
6. **固定摘要窗口切开英文词**：独立审查发现窗口会把 OpenAI/Airbnb 的片段误算成独立 AI。输出窗口扩展到完整词边界后再评分，开始和结束两侧都有回归。
7. **长工具展示被截断**：测试者能恢复结果，但曾原样重搜。检索说明补充“先保存完整 JSON，再分段读”，区分展示截断和原文分页。
8. **书籍跨页边界**：文档明确单页 has_more=false 不代表章节结束；跨页要逐页读与核对，当前不提供跨页合并引文核验。

独立审查结论及原始复现见 independent-review.md（历史记录，未随包提供）。
